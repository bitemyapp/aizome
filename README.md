# Aizome 藍染 has moved to Sekka

**Development continues in [bitemyapp/sekka](https://github.com/bitemyapp/sekka).**

Aizome, Sekka's Wayland desktop environment, now lives in the Sekka repository.
Use the links below for current source, documentation, and contributions:

- [Aizome source and documentation](https://github.com/bitemyapp/sekka/tree/main/desktop/aizome)
- [Report an issue in Sekka](https://github.com/bitemyapp/sekka/issues)
- [Pull requests in Sekka](https://github.com/bitemyapp/sekka/pulls)

To clone the active repository, including its submodules:

```sh
git clone --recurse-submodules https://github.com/bitemyapp/sekka.git
```

Open Aizome pull requests have been migrated to Sekka. Each original pull request
links to its destination.

This repository is retained for its history. The
[former standalone README](https://github.com/bitemyapp/aizome/blob/1a50f8ed25ee1f0e376fdb1ec52c8a74ab080d22/README.md)
is available for reference; follow the documentation in Sekka for current setup
and development instructions.
